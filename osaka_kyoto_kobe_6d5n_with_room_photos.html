DAY 1｜10/04

抵達大阪・梅田

抵達後 關西機場 → 機場巴士／電車 → 飯店寄放行李。

下午 LUCUA・Grand Front Osaka・Yodobashi。

晚上 梅田晚餐 → 空中庭園展望台。

DAY 2｜10/05

京都・清水寺東山

大阪 → 京都 → 清水寺 → 二年坂・三年坂 → 八坂神社 → 祇園 → 大阪。

DAY 3｜10/06

大阪・市區

大阪城 → 黑門市場 → 心齋橋 → 道頓堀。

DAY 4｜10/07

神戶・港灣

大阪 → 三宮 → 北野異人館 → 南京町 → Meriken Park → 神戶港夜景 → 大阪。

DAY 5｜10/08

京都・伏見稻荷＋嵐山

大阪 → 伏見稻荷 → 嵐山竹林 → 渡月橋 → 大阪。

DAY 6｜10/09

梅田最後購物・機場

退房 → 免費寄放行李（依飯店規定）→ 梅田購物 → 取行李 → 機場。

✈️ 關西機場 → 梅田

兩人＋行李優先考慮Limousine Bus，減少轉乘。

🚆 大阪 → 京都

JR適合京都站／伏見稻荷；阪急適合河原町／祇園。

🚆 大阪 → 神戶

JR大阪→三ノ宮速度快；阪急大阪梅田→神戶三宮。

🚇 大阪市區

梅田、心齋橋、難波、大阪城以Osaka Metro＋IC卡為主。
